📧 EMAIL CONFIGURATION (Gmail SMTP)

🔟 SMTP Host
    Name: SMTP_HOST
    Value: smtp.gmail.com

1️⃣1️⃣ SMTP User (Gmail Address)
    Name: SMTP_USER
    Value: your-email@gmail.com
    
    Use your Gmail account that will send emails

1️⃣2️⃣ SMTP Password (App Password - NOT Regular Password!)
    Name: SMTP_PASS
    Value: [16-character Gmail App Password]
    
    To generate:
    1. Go to myaccount.google.com
    2. Enable 2-Factor Authentication
    3. Go to "App passwords" (search: myaccount.google.com/apppasswords)
    4. Select "App: Mail" and "Device: Windows Computer"
    5. Google will generate 16-character password
    6. Copy (without spaces) and paste here
    
    ✓ Example format: abcdefghijklmnop (16 characters, lowercase)

1️⃣3️⃣ SMTP From (Sender Address)
    Name: SMTP_FROM
    Value: noreply@hunar-asaan.com
    
    Can be same as SMTP_USER or different "from" address
